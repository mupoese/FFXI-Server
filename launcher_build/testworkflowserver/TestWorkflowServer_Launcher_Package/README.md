# TestWorkflowServer Server Launcher

This launcher provides a complete interface for connecting to the TestWorkflowServer server with authentication and client management.

## Features

- **Server Authentication**: Login with your TestWorkflowServer server credentials
- **Real-time Status**: Monitor server status and player count
- **Ashita Integration**: Full Ashita v4 compatibility for enhanced gameplay
- **Client Management**: Automatic client validation and configuration
- **Multi-platform Support**: Works on Windows, macOS, and Linux

## Quick Start

1. Run `TestWorkflowServer_Launcher.exe`
2. Enter your username and password (default: admin/admin123)
3. Configure your client settings
4. Launch your TestWorkflowServer client!

## Configuration

The launcher reads configuration from `.env` files. Copy `.env.example` to `.env` and modify as needed.

### Key Settings

- `TestWorkflowServer_SERVER_HOST`: Server hostname or IP address
- `TestWorkflowServer_LOGIN_PORT`: Server login port
- `TestWorkflowServer_ADMIN_USERNAME`: Your admin username
- `TestWorkflowServer_ADMIN_PASSWORD`: Your admin password
