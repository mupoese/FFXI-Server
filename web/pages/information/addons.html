Install Guide

📋 Installation Guide

1

Download Windower 4

Download the latest version of Windower 4 from the official website.

Download Windower
2

Install and Configure

Run the installer and point it to your FFXI installation directory.

C:\Program Files (x86)\PlayOnline\SquareEnix\FINAL FANTASY XI\
3

Add Server Settings

Configure Windower to connect to our server:

Server: your-server-address.com
Port: 54001
Username: your-username
Password: your-password
4

Install Addons

Use the Windower addon manager or manually install addons to the addons folder.

Addon path: Windower4/addons/

🔧 Troubleshooting

Windower won't start

Make sure you're running as administrator and have the correct FFXI path configured.

Addons not loading

Check that addons are in the correct folder and enabled in the Windower settings.

Performance issues

Try disabling resource-intensive addons like GearSwap if experiencing lag.

Connection problems

Verify server address and port settings. Check firewall permissions.
