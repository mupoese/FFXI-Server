# Streaming and Asset Management Tools

This directory contains streaming services, asset management, and FFXI-specific streaming tools.

## Tools

### Streaming Services
- `ffxi_streaming_service.py` - Core FFXI streaming service
- `streaming_manager.py` - Stream management and coordination
- `streaming_cli.py` - Command-line streaming interface
- `streaming_dashboard_api.py` - Streaming dashboard API

### Asset Management
- `ffxi_asset_extractor.py` - FFXI asset extraction and processing
- `ffxi_renderer.py` - FFXI asset rendering system

### AI-GM Integration
- `aigm_streaming_integration.py` - AI-GM streaming integration

### Testing
- `test_streaming_system.py` - Streaming system testing

## Usage

### Streaming Service
```bash
python ffxi_streaming_service.py
```

### Asset Extraction
```bash
python ffxi_asset_extractor.py
```

### Streaming Management
```bash
python streaming_manager.py
python streaming_cli.py
```

### Testing
```bash
python test_streaming_system.py
```

## Features

- FFXI asset extraction and processing
- Real-time streaming services
